# README demo GIFs

Assets live in `docs/assets/demo/` and are embedded in the root [README.md](../../README.md).

## Files

| File | Suggested flow |
|------|----------------|
| `scan.gif` | Choose scan targets → run scan → candidate list with sizes |
| `cleaning.gif` | Select safe items → preview cleanup → quarantine result |
| `settings.gif` | Settings overview (language, discovery, safety) |

## Recording tips

- Use **English** UI (default locale) for consistency on GitHub.
- Window size ~1280×720 or 1440×900; keep motion under ~15s per GIF.
- Avoid real paths, tokens, or machine-specific usernames in view.
- Prefer **dry-run / quarantine** flows; do not record destructive deletes on production data.
- Compress GIFs (e.g. ScreenToGif, LICEcap) — aim for each file under ~5–8 MB if possible.

## After recording

1. Replace files in `docs/assets/demo/`.
2. Update README **Demo** caption line if behavior changed.
3. Open README on GitHub preview to confirm tables and images render.
