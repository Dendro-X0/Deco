## Problem statement

v0.6.0–0.6.1 improved scan wall time, but regressions were only caught manually on large drives. Maintainers need a **deterministic synthetic tree**, a **headless timing harness**, and **CI limits** so performance changes are visible in PRs.

Goals for `v0.6.2`:

1. **`deco-bench` binary** — times discover / classify / size on a generated fixture.  
2. **Baseline JSON** — upper bounds + regression ratio; fails CI when exceeded.  
3. **Docs** — how to run locally and update baselines after intentional wins.

**Non-goals:** real-drive benchmarks in CI, Quick-update bench (optional follow-up), publishing bench results as artifacts.
