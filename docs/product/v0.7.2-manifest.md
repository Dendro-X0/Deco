# v0.7.2 manifest — Policy pack validation (draft)

**Status:** In progress  
**Target release:** `v0.7.2`  
**Theme:** Validated, shareable **`.deco` policy packs** — CLI validator + curated examples so teams can adopt excludes and safety lists without forking ad-hoc JSON.

Parent: [v0.7.x-roadmap.md](v0.7.x-roadmap.md) · Follows [v0.7.1-manifest.md](v0.7.1-manifest.md).

## Problem

- `.deco/disk-cleanup.json` is supported (see [milestone-3](../milestones/milestone-3.md)) but there is no **validate-before-merge** workflow for shared team presets.
- Example packs under [examples/deco-policies](../../examples/deco-policies/) are undocumented in the product CLI surface.

## Candidate scope

| ID | Deliverable | Notes |
|----|-------------|--------|
| **V1** | **`deco validate-policy` (or subcommand)** | Validate a policy file or `.deco/` tree against `apps/cli/config.schema.json`; clear errors, exit code ≠ 0 on failure |
| **E1** | **Examples repo polish** | Document [examples/deco-policies](../../examples/deco-policies/); link from CLI help and docs |
| **D1** | **Docs + tests** | Manifest checklist; Vitest for validator; CHANGELOG [Unreleased] |

## Non-goals

- Community policy marketplace or signed packs  
- Desktop UI importer for policy packs (CLI-first in 0.7.2)  
- Changing merge semantics for `.deco` files without schema bump
