# v0.8.0 manifest — Multi-platform installers

**Status:** Draft  
**Target release:** `v0.8.0`  
**Theme:** Release desktop installers and CLI packages for **Windows, macOS, and Linux** from CI — completes Phase E “platform reach” foundation.

## Problem

- [release.yml](../../.github/workflows/release.yml) builds **Windows-only** installers today; CI tests on Ubuntu/macOS but does not ship bundles.
- Maintainer primary OS is Windows; releases must still deliver Linux and macOS artifacts for all users.

## Scope

| ID | Deliverable | Status |
|----|-------------|--------|
| **R1** | **Icons & Tauri bundle targets** | Planned — `icon.icns`, PNG set; `dmg`, `deb` and/or `appimage` in `tauri.conf.json` |
| **R2** | **Release workflow matrix** | Planned — `windows-latest`, `macos-latest`, `ubuntu-latest` build jobs; attach all artifacts to GitHub Release |
| **R3** | **Per-OS CLI zips** | Planned — `deco-cli-win-x64`, `deco-cli-macos-x64`, `deco-cli-linux-x64` (Node 20+ documented) |
| **R4** | **In-app updates** | Planned — verify `pickPlatformDownloadAssets` / installer handlers for non-Windows assets |
| **D1** | **Docs** | Planned — [github-releases.md](../distribution/github-releases.md), [ci-and-release-platforms.md](../distribution/ci-and-release-platforms.md) |
