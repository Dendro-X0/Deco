# v0.7.x — Trust, explainability, community

**Status:** In progress (**`v0.7.0`** — see [v0.7.0-manifest.md](v0.7.0-manifest.md))  
**Intent:** Phase D after **v0.6.x** scan engine — help users **trust** recommendations (profiles, dormancy, policy packs) without weakening quarantine-first safety.

**Prerequisite:** [v0.6.12](v0.6.12-manifest.md) shipped (scan contract **2.8.0**).

---

## North star for 0.7.x

1. **Explain before delete** — regeneration commands, dormancy context, clear profile intent.  
2. **Shareable policy** — validated `.deco` snippets, not ad-hoc JSON forks.  
3. **Parity** — TS CLI and Rust engine stay aligned on classification fixtures.  
4. **No safety regression** — profiles and hints are suggest-only; review/blocked tiers unchanged.
