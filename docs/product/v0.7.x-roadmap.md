# v0.7.x — Trust, explainability, community

**Status:** **`v0.7.8`** in development — see [v0.7.8-manifest.md](v0.7.8-manifest.md)  
**Intent:** Phase D after **v0.6.x** — help users **trust** recommendations (profiles, dormancy, policy packs) without weakening quarantine-first safety.

**Prerequisite:** [v0.7.0](v0.7.0-manifest.md) shipped · [v0.6.12](v0.6.12-manifest.md) (scan contract **2.8.0**).

**Process:** One feature set per version, in order. Do not skip ahead; complete each manifest before tagging.

---

## North star for 0.7.x

1. **Explain before delete** — regeneration commands, dormancy context, clear profile intent.  
2. **Shareable policy** — validated `.deco` snippets, not ad-hoc JSON forks.  
3. **Parity** — TS CLI and Rust engine stay aligned on classification fixtures.  
4. **No safety regression** — profiles and hints are suggest-only; review/blocked tiers unchanged.

## Non-goals (0.7.x line)

- Full community profile marketplace  
- Auto-delete or bypassing review phrase for “stale” heuristics  
- Plugin/signed third-party kinds (research only — not a 0.7.x ship)  
- Multi-platform release CI (→ `v0.8.0`)  
- README product demos (→ `v0.8.3`)
