# v0.6.1 manifest — Incremental inventory

**Status:** Shipped (2026-05-15)  
**Release:** `v0.6.1`  
**Theme:** Faster repeat scans by reusing classified + sized candidates when paths are unchanged.

Parent plan: [version-roadmap.md](version-roadmap.md) Phase C3 · Experiment notes: [../experiments/incremental-inventory.md](../experiments/incremental-inventory.md).

## Problem statement

After a **full** scan, users often re-scan the same drive to pick up small changes. v0.6.0 made classify/size faster, but **discovery + classify + size** still repeat for every target. Most paths are unchanged between runs.

Goals for `v0.6.1`:

1. **SQLite path inventory** — cache candidate metadata keyed by normalized path + config fingerprint.  
2. **Quick update** — discover as today; skip classify/size when `mtime` matches inventory.  
3. **Full rescan** — unchanged behavior; refreshes inventory.  
4. **User control** — experimental setting + per-scan **Scan Now** vs **Quick update**.

**Non-goals (0.6.1):** skip directory walks / USN journal (`v0.6.2+` / experimental), cross-machine sync, inventory export.

## Technical design

### Inventory row

| Column | Purpose |
|--------|---------|
| `abs_path` | Normalized absolute path (PK) |
| `config_fingerprint` | Hash of profile, stale_days, discovery flags, path policy lists |
| `mtime_ms`, `size_bytes` | Change detection |
| `kind`, `risk`, `safety_class`, … | Serialized candidate fields (wire keys) |
| `candidate_id` | Stable id for UI selection continuity when reused |
| `last_scan_id`, `updated_at` | Audit |

### Quick update flow

```
discover (unchanged walker)
    ↓
for each target:
    if inventory hit (same fingerprint + mtime) → push CleanupCandidate, skip work
    else → queue for classify/size pipeline
    ↓
persist scan + upsert inventory + prune removed paths under roots
```

### Fingerprint

Includes: `profile`, `stale_days`, ecosystem/discovery flags on `ScanRequest`, sorted exclude/protect/allow lists. Excludes: selected volumes / roots (scan geometry is not part of classification rules).
