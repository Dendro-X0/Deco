# v0.6.12 manifest — Bazel disk cache + Android / Gradle `.cxx`

**Status:** Shipped (`v0.6.12`, 2026-05-17)  
**Target release:** `v0.6.12`  
**Theme:** Optional breadth after Xmake/Premake/Qt: Bazel **disk** cache via explicit env + layout checks, Android/Gradle **`.cxx`** intermediates — strong markers, review-tier defaults, contract **2.8.0**.

Parent: [v0.6.x-roadmap.md](v0.6.x-roadmap.md) · Follows [v0.6.11-manifest.md](v0.6.11-manifest.md).

---

## Problem

- **Bazel** workspace `bazel-*` outputs were covered in [v0.6.10](v0.6.10-manifest.md); a shared **`--disk_cache`** directory is still easy to miss and must not be guessed from arbitrary `bazel-*` paths.
- **Android NDK / CMake** external native build trees (**`.cxx`**) under Gradle were not first-class targets.

## Deliverables

| ID | Deliverable | Acceptance |
|----|-------------|------------|
| **B1** | **Bazel disk cache (global)** | Opt-in `check_bazel_disk_cache`; only when **`BAZEL_DISK_CACHE`** points at an existing directory with **`cas` and/or `ac`** layout; kind `bazel_disk_cache`; warnings if env set but layout missing |
| **A1** | **Gradle / Android `.cxx`** | `balanced+`; ancestor has JVM/Gradle markers (incl. `gradlew` / `gradlew.bat`); skip descent into `.cxx`; classify **review** (`GRADLE_ANDROID_CXX_BUILD`, …) |
| **P1** | **Inventory fingerprint + docs** | `inventory_fingerprint` includes `check_bazel_disk_cache`; [contract/changelog.md](../contract/changelog.md) **2.8.0** + [v0.6.x-roadmap](v0.6.x-roadmap.md) fingerprint note |

## Non-goals

- Auto-delete or lowering review tier on global caches  
- Heuristic discovery of disk cache under `output_user_root` without env + layout proof

## Settings ↔ engine (Quick update fingerprint)

Quick update reuses cached classify/size rows when `inventory_fingerprint` matches. That fingerprint (see `inventory_fingerprint` in `apps/desktop/src-tauri/src/engine/inventory.rs`) includes `profile`, `stale_days`, every global-discovery **`check_*`** flag (including `check_bazel_disk_cache`), and the exclude / extra-protected / allow path lists. Toggle any of these after a full scan if results look stale.
