# v1.0 manual QA script

Run on **installed release builds** (not `pnpm dev:desktop`) before tagging **`v1.0.0`**. Complete during **`v0.9.11`** on the latest `0.9.x` RC or tagged build.

Parent: [v1.0.0-manifest.md](v1.0.0-manifest.md) · [v0.9.11-manifest.md](v0.9.11-manifest.md)

Record results in the checkboxes below or in the release PR notes. File **P0/P1** issues only; defer cosmetic items to post-1.0.

**Solo-maintainer note:** If you only have Windows hardware, complete **A1** manually and treat **A2/A3** as satisfied when the **Release workflow** builds macOS `.dmg` and Linux `.deb`/`.AppImage` on the tag (see [§ Cross-platform without local Mac/Linux](#cross-platform-without-local-maclinux) below). Optional: run **CLI smoke (§ D)** on Linux via WSL using the release zip.

## Cross-platform without local Mac/Linux

Deco has shipped **three-platform installers since v0.8.0**. When you cannot run a Mac or Linux desktop VM:

| Criterion | Substitute evidence |
|-----------|-------------------|
| **A2 macOS desktop** | Release job **Build (macos)** succeeds; `.dmg` attached to the GitHub Release. Manual GUI smoke deferred — document in sign-off. |
| **A3 Linux desktop** | Release job **Build (linux)** succeeds; `.deb` + `.AppImage` attached. Optional partial check: CLI zip in **WSL** (§ D). |
| **D CLI** | Download `deco-cli-linux-x64.zip` or `deco-cli-macos-aarch64.zip` from the release; run `deco --help` and a dry-run scan (needs Node 20+). |

**What CI does not replace:** first-launch WebView, quarantine restore, or Settings UX on macOS/Linux. For **1.0**, a common solo-maintainer bar is: **Windows manual QA (A1) + green Release CI on the tag + no open P0 platform bugs**. Note limitations in the sign-off table.

**After 1.0:** encourage Mac/Linux users to report install issues; consider a contributor smoke test before the next major tag.

## A — Core cleanup loop (all platforms)

### A1 — Windows (MSI or NSIS)

- [x] Fresh install launches; Dashboard shows scan CTA
- [x] **Full scan** completes; safe-tier rows pre-selected
- [x] **Preview cleanup** totals match selection
- [x] **Quarantine** execute (safe-only) moves files; items appear in Quarantine tab
- [x] **Restore** one item; path works again
- [x] **Review tier:** selecting review row requires checkbox + `DELETE REVIEW` in preview
- [x] **History → Reuse Config** triggers rescan with same roots
- [x] **Free-space planner:** Plan safe → preview → quarantine succeeds

_Maintainer sign-off: Windows installed build verified (core loop)._

### A2 — macOS (dmg)

- [ ] App opens from `/Applications`; WebView loads _(manual deferred — rely on Release **Build (macos)** + `.dmg` artifact)_
- [ ] Scan + safe quarantine + restore (same as A1 core bullets)
- [ ] Settings → Tool storage migration shows **unsupported platform** message (expected)

### A3 — Linux (AppImage or deb)

- [ ] App launches; scan + quarantine + restore (same as A1 core bullets) _(manual deferred — rely on Release **Build (linux)** artifacts)_
- [ ] Migration section shows unsupported message (expected)

## B — Trust & guardrails (v0.9.10+)

### B1 — Scan-root warnings (any OS)

- [ ] Enable **Custom folders** scan mode
- [ ] Add a path matching a toolchain cache (e.g. `%USERPROFILE%\.cargo` on Windows)
- [ ] Warning panel appears; **Start scan** blocked until **Scan anyway** or **Remove**

### B2 — Migration handoff (Windows only)

- [ ] If OS volume is below threshold (or simulate on test VM): handoff banner appears on Dashboard
- [ ] **Open Tool storage migration** opens Settings and focuses migration section
- [ ] Dismiss banner; stays dismissed for session

### B3 — Tool storage migration (Windows)

- [ ] Settings section labeled **Windows · NTFS** (or equivalent platform badge)
- [ ] **Plan** for a known profile shows paths + warnings
- [ ] Dest-root leaf warning when destination includes tool folder name (e.g. `...\Cursor` as root)
