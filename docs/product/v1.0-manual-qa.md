# v1.0 manual QA script

Run on **installed release builds** (not `pnpm dev:desktop`) before tagging **`v1.0.0`**. Complete during **`v0.9.11`** on the latest `0.9.x` RC or tagged build.

Parent: [v1.0.0-manifest.md](v1.0.0-manifest.md) · [v0.9.11-manifest.md](v0.9.11-manifest.md)

Record results in the checkboxes below or in the release PR notes. File **P0/P1** issues only; defer cosmetic items to post-1.0.

---

## Prerequisites

- [ ] Download artifacts from the [GitHub Release](https://github.com/Dendro-X0/Deco/releases) under test
- [ ] Machine has at least one real dev project (JS or Rust recommended) with reclaimable artifacts
- [ ] Note build: version `________` · tag `________` · date `________`

---

## A — Core cleanup loop (all platforms)

### A1 — Windows (MSI or NSIS)

- [ ] Fresh install launches; Dashboard shows scan CTA
- [ ] **Full scan** completes; safe-tier rows pre-selected
- [ ] **Preview cleanup** totals match selection
- [ ] **Quarantine** execute (safe-only) moves files; items appear in Quarantine tab
- [ ] **Restore** one item; path works again
- [ ] **Review tier:** selecting review row requires checkbox + `DELETE REVIEW` in preview
- [ ] **History → Reuse Config** triggers rescan with same roots
- [ ] **Free-space planner:** Plan safe → preview → quarantine succeeds

### A2 — macOS (dmg)

- [ ] App opens from `/Applications`; WebView loads
- [ ] Scan + safe quarantine + restore (same as A1 core bullets)
- [ ] Settings → Tool storage migration shows **unsupported platform** message (expected)

### A3 — Linux (AppImage or deb)

- [ ] App launches; scan + quarantine + restore (same as A1 core bullets)
- [ ] Migration section shows unsupported message (expected)

---

## B — Trust & guardrails (v0.9.10+)

### B1 — Scan-root warnings (any OS)

- [ ] Enable **Custom folders** scan mode
- [ ] Add a path matching a toolchain cache (e.g. `%USERPROFILE%\.cargo` on Windows)
- [ ] Warning panel appears; **Start scan** blocked until **Scan anyway** or **Remove**

### B2 — Migration handoff (Windows only)

- [ ] If OS volume is below threshold (or simulate on test VM): handoff banner appears on Dashboard
- [ ] **Open Tool storage migration** opens Settings and focuses migration section
- [ ] Dismiss banner; stays dismissed for session

### B3 — Tool storage migration (Windows)

- [ ] Settings section labeled **Windows · NTFS** (or equivalent platform badge)
- [ ] **Plan** for a known profile shows paths + warnings
- [ ] Dest-root leaf warning when destination includes tool folder name (e.g. `...\Cursor` as root)

---

## C — Upgrade & data retention

- [ ] Upgrade from previous `0.9.x` install preserves Settings
- [ ] Quarantine entries from prior version still listed (if applicable)
