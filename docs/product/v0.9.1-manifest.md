## Why v0.9.1

The `v0.9.0` Git tag was pushed before package versions were bumped, so GitHub Release installers were built as `Deco_0.8.5_*`. Force-pushing the tag does not replace uploaded assets. **v0.9.1** is the corrective production release plus the next slice of migration profiles.
