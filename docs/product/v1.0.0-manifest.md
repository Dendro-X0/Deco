# v1.0.0 manifest — GA developer cleanup

**Status:** Planned (after `v0.9.11`)  
**Theme:** **Safe to recommend blindly** for scan → review → quarantine → restore on Windows, macOS, and Linux.

Parent: [v1.0-roadmap.md](v1.0-roadmap.md)

**Ship when:** every **exit criterion** below is checked, `pnpm check` green, three-platform Release CI green, version sources at `1.0.0`, tag `v1.0.0`.

---

## Positioning

**Deco 1.0** is the **developer cleanup** release:

- Whitelist artifact kinds, explain every row, quarantine-first defaults.
- CLI and desktop share a **stable scan contract** and fixture-tested classification.
- **Tool storage migration** ships as a **Windows-only** Settings feature with clear labeling — not part of scan `schema_version`.

## Explicit non-goals (1.0)

- macOS/Linux tool-directory migration  
- Automated migration rollback in one click  
- Merged TS+Rust single classifier binary  
- Yarn / pip / Conda cache kinds  
- General-purpose file browser / Documents cleanup  
- Plugin / third-party kind loading at runtime
