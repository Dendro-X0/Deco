# v0.8.x — Platform reach & distribution

**Status:** **`v0.8.1`** in progress — see [v0.8.1-manifest.md](v0.8.1-manifest.md)  
**Intent:** Phase E — ship Deco installers on **Windows, macOS, and Linux** from CI, then widen distribution and polish. One feature set per version.

**Prerequisite:** [v0.7.8](v0.7.8-manifest.md) (Phase D complete).

**Distribution target:** Every `v0.8.0+` release publishes desktop installers for all three platforms plus per-OS CLI archives (see [ci-and-release-platforms.md](../distribution/ci-and-release-platforms.md)).

---

## North star for 0.8.x

1. **Same product on three OSes** — build, test, and release from GitHub Actions without a local Mac/Linux box for routine cuts (manual smoke on each OS when possible).  
2. **Convenient install** — winget / Homebrew after native bundles exist.  
3. **Broader audience** — localized UI and README demos for onboarding.  
4. **Optional speed** — Windows inventory fast path stays experimental and gated.

---
