## Problem

Teams using **Xmake**, **Premake**, or **Qt/qmake** still see empty scan results for standard out-of-tree build folders unless they fall under generic `build/` heuristics without project proof.

## Deliverables

| ID | Deliverable | Acceptance |
|----|-------------|------------|
| **X1** | **Xmake** | `.build` when `xmake.lua` on ancestor (`balanced+`) |
| **P1** | **Premake** | `bin-int` / `bin-int64` when `premake5.lua` / `premake4.lua` on ancestor |
| **P2** | **Premake `obj/`** | `obj` when Premake markers present and **no** .NET project markers |
| **Q1** | **Qt/qmake shadow builds** | `build-*` (not `bazel-*`) when `.pro` / `.qmake.stash` on ancestor |
| **T1** | **Parity + tests** | Shipped — Rust + CLI; `pnpm check` green |
