# v0.7.8 manifest — Workspace rollups

**Status:** In progress  
**Target release:** `v0.7.8`  
**Theme:** **Monorepo workspace rollups** — summarize reclaim by project root without double-counting (deferred from original `v0.7.7` plan).

Parent: [v0.7.x-roadmap.md](v0.7.x-roadmap.md) · Follows [v0.7.7-manifest.md](v0.7.7-manifest.md).

## Problem

- Large monorepos show flat candidate lists; users cannot see per-workspace or per-root totals before selecting cleanup.
- Double-counting parent/child paths undermines trust in planner totals.

## Scope

| ID | Deliverable | Status |
|----|-------------|--------|
| **W1** | **Rollup model** | Planned — group candidates by detected `project_root` (or scan root); safe/review/blocked subtotals |
| **U1** | **Dashboard UX** | Planned — rollup panel or grouped summary; selection respects groups without duplicate bytes |
| **T1** | **Tests** | Planned — unit tests for grouping and size aggregation |
| **D1** | **Docs** | Planned — user guide + features |

## Non-goals

- Auto-delete by rollup tier  
- Cross-machine sync of rollups  
- Scan contract bump unless wire shape requires documented bump
