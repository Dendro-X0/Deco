# v0.9.9 manifest — Managed migrations registry (M3)

**Status:** Shipped (`v0.9.9`)  
**Target:** Windows NTFS junction migrations (extends v0.9.x wizard)

---

## Goal

Give users a **durable list** of directory migrations Deco has performed or detected — with quick paths to verify junctions and **manual rollback** guidance — without hunting audit JSON files.

---

## Scope

| ID | Feature | Notes |
|----|---------|--------|
| **M3a** | SQLite `managed_migrations` table | One row per source path; upsert on successful Run |
| **M3b** | Junction discovery on list | Scan known profile sources; register existing junctions as “detected” |
| **M3c** | Settings UI — “Your migrations” | List, Open source/dest, dismiss entry, rollback guide link |
| **M3d** | Destination-root leaf warning | Plan warns when dest root ends with `Cursor`, `Code`, etc. |
| **M3e** | CLI parity | `dest-root-warning.ts` on `migrate-tool-dir plan` |

## Out of scope (v0.9.9)

- Automated rollback (restore backup + remove junction in one click)
- Custom-folder rows in discovery (profile sources only)
- macOS/Linux desktop migration

---

## Acceptance checks

- [ ] After Run, migration appears under **Your migrations**
- [ ] Pre-existing Cursor junction appears as **detected** on first Settings visit
- [ ] Plan with `G:\DevToolData\Cursor` shows dest-root warning
- [ ] Dismiss removes row only; junction unchanged
- [ ] `pnpm test:rust` + CLI tests green
